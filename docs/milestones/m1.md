# M1 — Package the Four Skills

## Scope

- Collect the four conversation-produced skills under `skills/`.
- Preserve their supporting resources and authored evaluation definitions.
- Exclude caches, generated worktrees, raw logs, and machine-specific configuration.
- Add repository documentation, a deterministic package validator, and minimal CI.
- Run local validation before publication.

## Non-goals

- Changing the semantics of any skill.
- Adding a plugin marketplace manifest.
- Installing or modifying the user's global Codex configuration.

## Acceptance Criteria

- Exactly the four requested skill packages are present.
- Every package has a valid `SKILL.md` and usable supporting files.
- Local validation and focused helper tests pass.
- CI mirrors the documented deterministic checks.
- No credentials, caches, raw logs, or machine-local paths are tracked.
