# M2 — Add `create-issue`

## Scope

- Add an independent `create-issue` skill package with `SKILL.md`, UI metadata, GitHub CLI reference, deterministic wrapper, and behavior-evaluation matrix.
- Update collection packaging documentation, validator expectations, and CI help checks.
- Preserve the four existing skill contracts.

## Non-goals

- Implementing or fixing application source code.
- Modifying PRD/EDD at runtime when the skill is used.
- Creating live GitHub Issues during local evaluation.
- Adding a plugin marketplace package or global Codex configuration.

## Acceptance Criteria

- `create-issue` is discoverable as a standalone `$create-issue` skill with valid frontmatter and UI metadata.
- The skill enforces settled-intent extraction, three-type taxonomy, duplicate detection, PRD/EDD conflict stops, split confirmation, concise issue bodies, and no-coding termination.
- The wrapper supports repository/auth checks, list/view, create, comment, edit, and minimal label handling through `gh` without accepting tokens as arguments.
- Local package validation and focused helper `--help` checks pass.
